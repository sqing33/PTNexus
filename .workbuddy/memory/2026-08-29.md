## 详情弹框宽度/滚动「不生效」根因复盘
- 用户反馈改了 900px + 滚动样式后仍无变化 → 两个根因：
  1. **运行的是构建产物 `webui/dist`**：前端改动必须 `pnpm run build` 后才会进入打包结果，否则页面仍是旧版（宽度 prop 自然不变）。已重新 `pnpm run build` 生成新 dist。
  2. **el-dialog CSS 真实 bug**：Element Plus 弹框默认 `--el-dialog-margin-top: 15vh`，与 `max-height: 90vh` 相加 105vh 超出视口，弹框被顶出屏幕、内部也滚不动。修正：把 `.resource-detail-dialog` / `.resource-edit-dialog` 的 `--el-dialog-margin-top` 改为 `5vh`（5+90=95vh 适配视口），并给 header 加 `flex-shrink:0`、body 维持 `flex:1; min-height:0; overflow-y:auto`。
- 结论：本项目前端运行在打包产物上，任何 `.vue` 改动都要走 `pnpm run build`；el-dialog 做 max-height 约束时必须同时收小 margin-top，否则滚动不生效。
